Solo se ofrece el campo cuyo slot esta visible, y con un solo valor no aparece. El chip y el pie hablan de lo filtrado; el visor recibe los items YA filtrados (el visor no filtra).

Visor (ambito 2)

Pendiente (el visor no lo acepta hoy): contador opcional, ancho de caja, flechas superpuestas, marco solido, segundo precio, nota al pie, icono en acciones, contenido libre y aviso de imagen rota. Veredicto: visor-evaluacion.md.

Editá el JSON (por ejemplo items) y tocalo para aplicarlo. Tambien acepta visor:{tono,meta,items,listado,segmentos,acciones,roto,rotoHasta} para fijar un escenario del modal de un pegado.

Galeria (ambito 1). Toca una imagen para abrir el visor, los + para cargar y el chip +N para las imagenes ocultas.
